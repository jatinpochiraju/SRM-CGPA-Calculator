**SRM CGPA Calculator** is a straightforward web-based tool designed to help students of SRM University calculate their Cumulative Grade Point Average (CGPA) efficiently.

## Features

- User-friendly interface for easy CGPA calculation.
- Input grades and credits for multiple subjects.
- Instant calculation of accurate CGPA.
- Lightweight and responsive design.

## Getting Started

1. Download or clone the repository.
2. Navigate to the project directory.
3. Open `cgpacalc.html` in your preferred web browser to start using the calculator.

## Project Structure

- `cgpacalc.html` - Main HTML file for the CGPA calculator.
- `Website/` - Directory containing website assets and additional resources.
- `Screenshot.png` - Image showcasing the application's interface.
